# 세이빙스쿨 풀페이지 스크롤

한 화면에 한 장씩 넘기는 세이빙스쿨 소개 페이지입니다. 빌드 과정 없이 파일 그대로 배포됩니다.

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 페이지 본문 (화면 6개) |
| `css/style.css` | 모양: 상단 바, 화면보다 작은 이미지 둘레 채우기, 오른쪽 이동 점 |
| `js/fullpage.js` | 한 화면씩 넘기는 동작: 마우스 휠, 트랙패드, 키보드, 터치, 오른쪽 점 |
| `images/` | 화면 이미지, 로고, 노란 물음표 버튼, 파비콘 |

## 화면 순서

1. `hero.webp` 첫 화면 (상단 바는 이미지가 아니라 HTML로 만들어 높이를 줄였습니다)
2. `seminar.webp` 지금 볼 수 있는 세미나
3. `upcoming.webp` 오픈 예정 강의
4. `education.webp` 체계적인 전문 교육이 필요한 때
5. `class.webp` 깊이 배우고, 새롭게 발견하는 곳
6. `faq.webp` 자주 묻는 질문 + 회사 정보, 노란 물음표 버튼 `help-button.svg`

## 이미지 바꾸는 법

`images` 폴더의 파일을 같은 이름으로 바꾸면 됩니다. 가로·세로 크기가 달라지면 `index.html`에서 그 이미지의 `--w`, `--h` 값과 `width`, `height` 값을 새 크기로 고쳐 주세요. 화면보다 작은 부분은 자동으로 배경색(검정 또는 연한 회색 `#ECECEA`)으로 채워집니다.

## 조작

- 마우스 휠, 트랙패드: 위아래로 한 화면씩
- 키보드: ↑ ↓, Page Up / Page Down, Space, Home, End
- 휴대폰: 위아래로 밀기
- 오른쪽 점: 원하는 화면으로 바로 이동
- 주소 끝에 `#seminar`처럼 붙이면 그 화면부터 열립니다 (`#hero` `#seminar` `#upcoming` `#education` `#class` `#faq`)

## 배포

GitHub 저장소의 `main` 브랜치에 커밋을 올리면 Cloudflare Pages가 자동으로 새 버전을 배포합니다.
